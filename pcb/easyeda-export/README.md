# ThermalCamara (Pocket Thermal)

Handheld thermal camera: MLX90640 thermal sensor + ESP32-S3, designed in EasyEDA Pro v3.2.149.

## Repository layout

- `hardware/schematic/` – schematic PDF
- `hardware/project/` – EasyEDA Pro project file (`.epro2`), open in EasyEDA Pro to edit
- `manufacturing/gerbers/` – Gerber files for PCB fabrication
- `manufacturing/drill/` – Excellon drill files (plated, non-plated, via)
- `manufacturing/assembly/` – BOM and pick-and-place files for assembly
- `manufacturing/testing/` – flying probe test data
- `manufacturing/How-to-order-PCB.txt` – ordering instructions from EasyEDA

Exported 2026-10-11.
